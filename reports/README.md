# Reports

Longer-form notes that do not fit in a one-line summary: monthly round-ups,
comparisons of competing approaches, reading notes on a single paper.

Nothing here is auto-generated, so the format is up to you. A suggested naming
scheme:

```
reports/2026-07-monthly.md          # what happened this month
reports/agent-memory-designs.md     # a topic deep-dive
```

Link back to the paper entries in [README.md](../README.md) so readers can jump
between the summary and the detail.
